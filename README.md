# Sushi House Voice Robot

Технический MVP интеграции Mango Office и iikoCloud для Sushi House.

## Текущий этап

Версия `0.3.0`. Серверный каркас, авторизация, защищённые настройки и iikoCloud-диагностика готовы. Следующий этап — тестовый контур Mango SIP.

## Границы MVP

- закрытая административная панель;
- безопасное хранение и проверка интеграционных настроек;
- диагностика iikoCloud и чтение заказов без автоматических изменений;
- регистрация Mango SIP и контролируемые тестовые звонки;
- журнал звонков, SIP-событий и интеграционных ошибок;
- подготовленный HTTPS endpoint для Mango API Realtime;
- без подключения ИИ и без автоматических звонков реальным клиентам.

## Безопасность

До подключения домена и TLS админка доступна только через SSH-туннель. Секреты не хранятся в Git, не отображаются повторно после сохранения и не пишутся в журналы.

```bash
ssh -L 8080:127.0.0.1:8080 root@5.129.249.100
```

После установки туннеля интерфейс доступен по `http://127.0.0.1:8080`.

Подробный статус находится в [DEVELOPMENT_LOG.md](DEVELOPMENT_LOG.md), архитектура — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
