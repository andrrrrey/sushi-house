# Sushi House Voice Robot

Технический MVP интеграции Mango Office и iikoCloud для Sushi House.

## Текущий этап

Версия `0.12.0`. Входящий тестовый робот ведёт заказ строго пошагово и умеет вернуться из подтверждения к добавлению, удалению или замене позиций, после чего полностью повторяет обновлённый заказ. Простые этапы обрабатываются локально без лишнего обращения к языковой модели, а пауза определения конца реплики сокращена до 1,2 секунды. После первого разговора локально запоминается имя разрешённого тестового абонента. Подписанное событие Mango `Appeared` от разрешённого номера условно перенаправляется через API на внутренний номер 225; действующие номера клиента не перенаправляются роботу. Позиции сопоставляются с опубликованным внешним меню iiko, заказ сохраняется только локальным черновиком и не отправляется в iiko.

## Границы MVP

- закрытая административная панель;
- безопасное хранение и проверка интеграционных настроек;
- диагностика iikoCloud и чтение заказов без автоматических изменений;
- регистрация Mango SIP и контролируемые тестовые звонки;
- журнал звонков, SIP-событий и интеграционных ошибок;
- журнал входящих разговоров и структурированных черновиков заказа;
- редактируемая база знаний с пометкой спорных правил;
- подготовленный HTTPS endpoint для Mango API Realtime;
- Yandex SpeechKit и YandexGPT в тестовом режиме, доступном только с заранее разрешённого номера.

## Безопасность

Админка доступна через основной защищённый адрес:

<https://airobot.sushi03.ru>

Соединение защищено TLS, HTTP автоматически перенаправляется на HTTPS, а попытки входа ограничиваются на reverse proxy. Секреты не хранятся в Git, не отображаются повторно после сохранения и не пишутся в журналы.

SSH-туннель оставлен как резервный административный способ доступа:

```bash
ssh -L 8080:127.0.0.1:8080 root@5.129.249.100
```

После установки туннеля интерфейс доступен по `http://127.0.0.1:8080`.
